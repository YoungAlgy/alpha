## Contract

One fixed anonymous feed. Never send a profile/topic query, key or contact.
No article/media requests or model writing. The retained item is its original
decoded headline, credited author, first-party story URL and strict feed pubDate.
XML entity decoding and edge-whitespace extraction are formatting semantics.

headline/article prose is adapted into a narrative. Any later broader text use
needs its own scope/ShareAlike handling. This is not publisher legal assurance.

## Failure and cost policy

No-model and both durable controls are mandatory alongside the opt-in flag.
CDM follows earlier useful public sources and precedes optional GDELT. A valid
earlier signal short-circuits it. An unavailable/empty/exhausted CDM attempt falls
through without altering already usable work.

Fixed budget/circuit identity: `cdm-music`. Two reservations per fixed fifteen
minutes, no refunds. These are conservative ceilings, not published quota or
unlimited-service promises. Admission/budget failure prevents fetching. Missing
managed identity fails closed. The draft adds only one state/constraint identity,
preserving prior rows, permissions and RPCs. The isolated PostgreSQL rehearsal
passed76 checks. Managed installation is a separate guarded release step.

Five-second header/body deadline,256KiB response and projected-pool bounds,
no redirects/retries/pagination. Full XML envelope validation precedes the
100-valid-row cap. Current freshness, supported-topic match and normalized
prior-link exclusion run on every read before the one-item selection.
Known rejected or truncated rows mark an incomplete pool. The marker survives
cache reads, even when a reader has already seen all valid links. Such a result
cannot prove healthy-empty. All-invalid pools fail and enter the existing
cooldown. A valid empty feed stays empty. Optional diagnostics cannot throw
away validated partial work. A failed optional recovery completion cannot prove
recovery, but also cannot invalidate actual safe source metadata.

Raw feed cache/coalescing and a short local cooldown are per-process. The
existing protected limiter/circuit supply cross-run request/outage state.
The existing saved blurb and citation history supply durable content/repeat
state. Supabase remains required. No permanent availability claim.
